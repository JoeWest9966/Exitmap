出口端口（对外那一面）

      

        

          
起始端口重载 sing-box

            
出口端口从哪个号开始。改它等于整张表重排，所有客户端都要换端口。

          

        

        

          
监听地址重载 sing-box

            
出口端口绑在哪些地址上，一行一个。除了 127.0.0.1 可以再加本机的局域网/Tailscale 地址，让别的设备也能用。填 0.0.0.0 表示所有地址（那样就不需要再列别的）。

          

        

        

          
最大出口槽位重载 sing-box

            
端口表最多容纳多少个出口 IP，超出的按延迟优先保留。

          

        

        

          
国家端口段重载 sing-box

            
把端口按国家钉死：JP=31001-31020 表示 31001–31020 只给日本出口，日本 IP 死光了这些口就空着，绝不拿别国 IP 顶。没写进这里的国家只能用剩下的自由端口。逗号或换行分隔，两种行尾都行；保存后会立刻重排一次，那几个口会断一下。

          

        

        

          
关掉 UDP重载 sing-box

            
出口端口只走 TCP。有些客户端或上游对 UDP 有问题时打开。

          

        

      

    


    

      
探测

      

        

          
探活周期下一轮

            
多久重新探一遍所有节点，单位分钟。

          

        

        

          
拉订阅周期下一轮

            
多久重新拉一次订阅，单位分钟。机场换节点的节奏，跟探活分开。

          

        

        

          
探针地址下一轮

            
穿节点去读出口 IP 的地址，必须返回纯 IP，且必须是 http://（探针不走 TLS）。

          

        

        

          
探测超时下一轮

            
单个节点探多久算超时，毫秒。调小一轮更快，但慢节点会被误判。

          

        

        

          
探测并发下一轮

            
同时探多少个节点。越大一轮越快，也越吃带宽。

          

        

        

          
每轮最多探几个节点下一轮

            
节点很多时轮转抽样，避免一轮跑几十秒。0 表示不限。

          

        

        

          
连续失败几次才摘除下一轮

            
探不通一次不至于丢掉一个出口；连续失败到这个次数才真的退出轮询。

          

        

        

          
延迟上限下一轮

            
超过这么多毫秒的出口不上表，单位毫秒。0 表示不限。

          

        

      

    


    

      
日志

      

        

          
保留天数下一轮

            
换绑日志超过这么多天的自动清掉，比如写 1 就是只留最近一天。0 表示永久保留。

          

        

      

    


    

      
体检

      

        

          
端口与地址体检即时

            
看看有没有端口被别的进程占着（占了那个节点这一轮会被跳过），以及监听地址是不是真在本机上。
